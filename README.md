# MemeVault

Небольшой сайт с мемами, разделённый на два раздела: **2025** и **2026**.

## Запуск

```bash
npm install
npm run dev
```

Открой в браузере адрес из терминала (обычно http://localhost:5173).

## Страницы

| URL    | Описание        |
|--------|-----------------|
| `/`    | Главная         |
| `/2025`| Мемы 2025 года  |
| `/2026`| Мемы 2026 года  |

## Контент

В каждом году ровно **12 мемов** (по одному на месяц). Источники: [Know Your Meme — Meme of the Month](https://knowyourmeme.com/newsfeed/meme-review), календарь 2025, актуальные подборки трендов.

## Свои мемы от посетителей

Под каждым месяцем на `/2025` и `/2026` есть форма «Ваши мемы». Записи хранятся в **localStorage** браузера (видны только на этом компьютере). Общая доска для всех пользователей потребует сервер (например Supabase).

## Как изменить мем

Открой `src/data/memes.ts`: массивы `memes2025` и `memes2026`, поле `month` — число от 1 до 12.

## Сборка
